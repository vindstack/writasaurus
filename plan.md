Implement a local Deno-based desktop release command. The command must accept a semantic version, build Linux AppImage, macOS, and Windows artifacts using the existing project build commands, validate the output, generate SHA-256 checksums, and upload the artifacts to Cloudflare R2 using the S3-compatible API. Store files under immutable versioned paths. Generate release.json for each version and update latest.json with the current public download URLs. Configure the marketing site to read latest.json and render the platform download buttons. Credentials must come from local environment variables and must never be committed. Add dry-run support, upload verification, duplicate-version protection, and clear terminal output. No GitHub, GitHub Actions, or hosted build service should be required.
